# Identity and book requests

GitHub identity uses authorization code + PKCE, a signed ten-minute state cookie, and a Secure HttpOnly SameSite session cookie. Public user ID/login are kept in a signed seven-day session; no passwords, user table, email or provider token are stored. Current browser language preferences remain local; cross-device preferences and notification delivery need private durable storage or a notification service later. Different providers are not automatically merged into one account.

To enable GitHub, register an OAuth App for https://slowread-app.gmij.workers.dev/ with callback https://slowread-app.gmij.workers.dev/api/auth/github/callback. Add GITHUB_OAUTH_CLIENT_ID (variable), GITHUB_OAUTH_CLIENT_SECRET (encrypted runtime secret), AUTH_SESSION_SECRET (encrypted random secret, at least 32 characters). App registration/grants remain a separate user-approved action. The public content write token is never reused for user login. Unconfigured providers are not shown as working login buttons. Google/Apple/X integrations are not implemented or enabled yet.

Book requests currently open a prefilled Issue in gmij/slowread-library. The visitor reviews and submits using GitHub, and subscribes for GitHub notifications; admins reply with the reading link after confirming a licensed source. There is no background automatic fulfillment, browser push subscription, or automatic public Issue write endpoint. Direct submission from Slowread would need Issues write permission plus login/anti-abuse checks; the content Token only has Contents permission. Do not publish private notification endpoints, contact details, or account preferences in this public repository.
